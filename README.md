## Featured project · FineAlley

> **Your finances, organized. Your financial future, in focus.**

**FineAlley** is my ongoing full-stack project bringing personal finance management together with a long-term vision for investment tracking and a finance-focused community.

### What's implemented

- **Expense management** — record and manage expenses with search, filters, recurring transactions and CSV exports.
- **Spring Boot REST API** — Java backend with PostgreSQL persistence and database migrations using Flyway.
- **Telegram integration** — submit expenses and correct categories through a Telegram bot.
- **Local AI categorization** — semantic expense classification using local embeddings, with confirmation and personalized categories.
- **Responsive interface** — React-based application with light and dark modes.
- **Testing** — unit tests and **28 automated Playwright functional tests** documented in the project work.

### What's next

- 📈 Investment portfolio tracking and market-related features.
- 💬 Community features for sharing financial insights and exploring portfolios.
